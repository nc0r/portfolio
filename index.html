Telegram automation for barber shops

Appointments, reminders, and admin control in one Telegram bot.

A ready-to-customize Python bot that lets clients choose a service slot, leave contact details, receive reminders, and gives the shop an admin web panel.

What buyers get

01

Telegram booking flow

Clients select a service, available date and time, enter their name and phone, and receive confirmation.

02

Admin web panel

Staff can add free slots, inspect bookings, delete slots, and manage the schedule locally.

03

SQLite storage

Simple local database with migrations, no external paid service required for a demo or small shop.

04

Reminder scheduler

Automatic reminder jobs are restored after restart and skipped if the booking was removed.

Demo flow

  1. Admin adds appointment slots in Telegram or the web panel.
  2. Client opens the bot and checks services and prices.
  3. Client books a haircut, beard trim, or combo slot.
  4. Admin receives a Telegram notification with client details.
  5. The web dashboard shows live booking and slot statistics.

Tech stack

Python, aiogram 3, FastAPI, SQLite, APScheduler, Jinja2.

Security note

The public project uses `.env.example` only. Real bot tokens, logs, databases, and virtual environments are intentionally excluded.
